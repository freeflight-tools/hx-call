HX Call

Phone numbers for Swiss HX airspaces, sorted by how close you are. HX means no fixed operating hours — the zone can be activated at 30 minutes' notice, and you're allowed to check its status by phone. Useful if you don't carry a VHF radio.

Full page → Names, distances, notes, settings. For planning and for phones. Widget → Compact transparent buttons for the XCTrack Web page widget.

Widget configurator

Same URL as above. Point your phone's camera at it to open it there, then copy it into XCTrack.

Add it to XCTrack

  1. Add a Web page widget and paste the URL above.
  2. Turn on Allow web page to access XCTrack data — this is what gives it your position.
  3. Turn on Allow tapping on the web page when locked, or you can't press the call button in flight.
  4. Turn on Disable unlocking so a stray swipe doesn't rearrange it.
  5. Set refresh rate to 0 — the page updates itself.

This is a phone directory, not an airspace tool. It has no boundaries and no altitudes — use your flight computer for those. Numbers marked unverified still need checking against the current eVFR Manual. If you can't confirm a status, the airspace is active.
